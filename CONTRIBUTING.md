# Contributing

Issues and pull requests are welcome.

- Run `make check` before opening a pull request. It needs no GPU and no model download.
- Never add anyone's health information: no recordings, transcripts or notes from real visits. Every visit here is
  made up from a spec.
- Training data must come from open models whose licence allows their output to train other models (Apache 2.0 or
  MIT). Say which model and revision in the pull request.
- Generated visits, transcripts, training pairs and weights stay out of the repository (`data/private/` and `runs/`).

Clinicians who want to write or check right answers for test visits are especially welcome: write to info@metacare.ai.
